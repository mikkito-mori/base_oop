**Задание 1** 

**Кандидаты**:  
книга   
библиотека   
читатель 

**Атрибуты и поведение:**

1\. Книга  
Атрибуты:  
  isbn  
  название  
  автор  
 статус доступности  
Поведение:  
  изменить статус на «выдана»  
  изменить статус на «доступна»  
  сообщить текущий статус

2\. Библиотека   
Атрибуты:  
  каталог книг  
Поведение:  
  добавить книгу в каталог  
  выдать книгу читателю по ISBN  
  принять возврат книги по ISBN  
  показать список всех книг  
  показать список доступных книг  
  показать список выданных книг

  **Инварианты:**

1\. книга одновременно может быть только в одном статусе: либо «на полке», либо «выдана»  
2\. выданную книгу нельзя выдать повторно   
3\. у каждой книги уникальный ISBN  
4\. нельзя вернуть книгу, которая не была выдана.
